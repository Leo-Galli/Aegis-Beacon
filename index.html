PROGETTO APERTO SULLA SICUREZZA

Localizzatore Radio Emergenza d'Alta Montagna

Aegis-Beacon è un ecosistema firmware e hardware open-source progettato per garantire un'ancora di salvezza radio ridondante. Genera segnali ad impulsi agganciabili dai soccorritori a terra, garantendo visibilità radio dove le reti cellulari falliscono.

Specifiche Hardware Piano delle Frequenze
SPECIFICHE DI SISTEMA
Core Micro: ESP32-WROOM-32E / STM32
RF Transceiver: Semtech SX1262 LoRa
Output Power: Programmable up to +30dBm
Modulation: Direct CW Pulse (Morse / Ranging)
Battery Life: >72 Ore in trasmissione SOS
HW

Architettura Hardware Robusta

Nessun componente proprietario o debolezza strutturale. Il layout del circuito stampato è pensato per resistere a shock termici severi (-20°C a +40°C), umidità elevata e immunità ai disturbi elettromagnetici d'alta quota.

  • • Ebyte E22-400M30S: Amplificatore di potenza integrato per massimizzare la portata visiva (Line-of-Sight).
  • • Antenna Accordata: Connettore SMA ad alto isolamento per stilo a 1/4 d'onda o dipoli filari di fortuna.
  • • Alimentazione Protetta: Circuito di ricarica con diodi antiritorno e schermatura della cella LiPo.
PCB Layout v5.4: Gerber file pronti per la fabbricazione industriale.
FW

Logica del Firmware e Ottimizzazione

Scritto in C++ ottimizzato per consumi micro-ampere. Il loop principale implementa un watchdog hardware di sicurezza per prevenire blocchi del codice causati da picchi di tensione o sbalzi di temperatura esterni.

  • • CW Beacon Mode: Modulazione ad impulsi per massimizzare la ricezione da ricevitori SDR terrestri ed elicotteri.
  • • Iniezione Telemetria: Trasmissione automatica delle coordinate GPS catturate dall'ultimo fix valido prima del congelamento.
  • • Sleep Intelligente: Alternanza temporizzata trasmissione/riposo per raddoppiare l'autonomia energetica.
Core Engine compiled with RadioLib v6.1.0 or newer.

ℹ️ COMPORTAMENTO DELLA PORTANTE ANALOGICA SUL REALE CAMPO APPLICATIVO

Il chip radio Semtech SX1262 genera impulsi di radiofrequenza puri in onda continua (CW). I ricevitori commerciali e professionali dotati di display waterfall (SDR) vedranno apparire delle righe verticali nette e costanti in corrispondenza della frequenza di trasmissione. Questo garantisce l'individuazione della sorgente anche se sepolta sotto neve o barriere rocciose profonde, sfruttando la stabilità intrinseca del generatore di clock TCXO montato sul circuito di Aegis-Beacon.

1. Autocostruzione

Il progetto incoraggia lo sviluppo indipendente. Puoi ordinare i PCB tramite i file Gerber inclusi nel repository ed effettuare il flash del firmware tramite VS Code / PlatformIO.

2. Limitazioni Legali

La trasmissione è vincolata alle normative locali sulla potenza ERP. Assicurati di operare sui canali adibiti all'uso LPD/PMR senza violare le frequenze riservate allo Stato.
