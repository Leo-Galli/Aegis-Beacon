Ecosistema Aegis-Beacon v5.4

Manuale ingegneristico standardizzato per lo sviluppo, la calibrazione RF e il deployment sul campo dei dispositivi radio di localizzazione d'emergenza operanti su vettori UHF.

PARAMETRI HARDWARE CORE
Microcontrollore: ESP32-WROOM-32E
Ricetrasmettitore RF: Semtech SX1262 LoRa
Potenza d'Uscita Max: +30dBm (1W)
Modulazione Vettore: CW Pulse / Morse

1. Topologia Hardware e Vincoli di Rete

Il design dello stadio di amplificazione è strutturato attorno al modulo Ebyte E22-400M30S. L'alimentazione è provvista di un filtro pi-greco per l'abbattimento delle armoniche spurie e la protezione da sbalzi termici critici in ambienti montani.

  • - UHF Loop Only: 410 MHz — 525 MHz
  • - Antenna Port: SMA Impedance 50 Ohm
  • - Thermal Range: -20°C / +45°C Tested

2. Logica di Compilazione del Firmware

Codice nativo sviluppato in C++ sotto framework PlatformIO. Il firmware implementa routine a basso consumo energetico (deep sleep ciclico) e un controllo integrato dello stato di scarica della cella di alimentazione LiPo.

  • - Watchdog Timer: Hardware Level Enabled
  • - RF Engine Library: RadioLib Integration
  • - Telemetry Burst: Automated GPS String Injection
