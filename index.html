Ecosistema Aegis-Beacon v5.4

Un sistema di radiolocalizzazione d'emergenza a basso costo basato sulla tecnologia LoRa e progettato per il soccorso montano, terrestre e in scenari civili critici. Il beacon opera generando impulsi CW e messaggi digitali a lungo raggio per consentire il radiogoniometramento in condizioni di isolamento o assenza di infrastrutture cellulari.

[ AMBITO ]

Soccorso Alpino e Escursionistico

Consente ai dispersi di generare una traccia radio stabile e rintracciabile da squadre di terra equipaggiate con semplici ricevitori direzionali LPD o PMR446 compatibili.

[ TECNOLOGIA ]

RF Chirp e Segnale CW

Utilizza la modulazione LoRa e onde continue modulate a codice Morse per aumentare drasticamente la sensibilità del ricevitore (fino a -148dBm), penetrando la vegetazione fitta.

[ INDIPENDENZA ]

Infrastruttura Zero

Nessuna dipendenza da reti cellulari GSM, nodi internet o sistemi satellitari commerciali. Comunicazione diretta punto-punto peer-to-peer integrata ad alta efficienza.

Architettura Hardware dell'Unità RF

Il nucleo radio sfrutta l'accoppiamento tra il microprocessore dual-core ESP32 e il chip di ricetrasmissione a lungo raggio Semtech SX1262. Questa combinazione garantisce un'eccellente precisione nella generazione della portante e un consumo ridotto durante le fasi di deep-sleep.

[ Stadio Amplificatore RF ]

Ebyte E22-400M30S basato su SX1262. Integra un amplificatore di potenza (PA) e un amplificatore a basso rumore (LNA) in ricezione per estendere il link-budget a oltre 15 km in linea di vista ottica.

[ Sistema di Alimentazione ]

Circuito di ricarica LiPo TP4056 integrato con monitoraggio della tensione tramite partitore resistivo accoppiato al pin ADC dell'ESP32 per la telemetria dello stato di scarica.

Infrastruttura del Firmware

Scritto interamente in ambiente C++ su piattaforma PlatformIO per garantire prestazioni real-time ottimali e tempi di avvio del transceiver inferiori a 50 millisecondi.

La logica di trasmissione automatica interseca la telemetria analogica e i dati geografici estratti in formato NMEA da un eventuale modulo GPS seriale opzionale di tipo Neo-6M.

// STRUTTURA DEL PACCHETTO DI TELEMETRIA
[ PREAMBOLO: 8 byte ] [ ID UNITÀ: 2 byte ] [ STATO LIPO: 1 byte ] [ NMEA PAYLOAD ]

// config.h

#define RF_FREQUENCY     446081250 // PMR CH 7
#define TX_OUTPUT_POWER  30        // +30 dBm (1 Watt)
#define LORA_BANDWIDTH   125.0     // kHz
#define LORA_SP_FACTOR   9         // SF9 per bilanciamento
#define DEEP_SLEEP_SEC   120       // Ciclo risparmio energetico
Nota: Modificare la potenza di trasmissione in base alle normative nazionali vigenti.
[ PROCEDURA SOFTWARE DI COMPILAZIONE ]

Aggiornamento Firmware e Flash tramite PlatformIO

Il firmware di Aegis-Beacon viene compilato in codice macchina ed eseguito direttamente sul chip ESP32. Seguire rigorosamente la sequenza strumentale per caricare le patch software correttive o calibrare le frequenze operative.

FASE 01 // PREPARAZIONE

Scaricare e installare Visual Studio Code integrando il pacchetto PlatformIO IDE. Clonare il repository Git di sviluppo sul terminale locale. 

git clone https://github.com/Leo-Galli/Aegis-Beacon.git
FASE 02 // COLLEGAMENTO UART

Collegare il beacon al computer tramite convertitore USB-TTL (CP2102 o FTDI). Collegare RX a TX, TX a RX e GND in comune. Portare il pin GPIO0 a massa all'avvio per abilitare la modalità flash bootloader.

FASE 03 // COMPILAZIONE E FLASH

Aprire la cartella di progetto in VS Code, verificare i parametri nel file platformio.ini ed eseguire il comando combinato di build ed upload hardware. 

pio run --target upload
[ PROCEDURA STRUTTURALE DI ASSEMBLAGGIO ]

Manuale di Saldatura e Costruzione Fisica della PCB

L'assemblaggio dell'unità Aegis-Beacon richiede precisione e competenze basilari nell'ambito della saldatura SMD (Surface Mount Device). Seguire rigorosamente lo schema di montaggio dei componenti per evitare cortocircuiti o danni termici alle sezioni RF sensibili.

Specifiche della Distinta Componenti (BOM)

  • MCU: ESP32-WROOM-32E (Espressif Systems)
  • RF Subsystem: Modulo Ebyte E22-400M30S (SX1262)
  • Antenna Port: Connettore SMA femmina a 90 gradi saldabile
  • Power PMIC: Integrato TP4056 con diodi Schottky
  • Oscillatore: TCXO integrato a 32 MHz ad alta stabilità

Guida Operativa Passo-Passo

1. Saldatura dei Componenti Passivi

Saldare prima i resistori e i condensatori SMD con package 0805 o 0603, preferendo l'uso di pasta saldante ad alta conducibilità e stazione ad aria calda.

2. Allineamento dei Moduli Integrati

Posizionare accuratamente l'ESP32 e il chip SX1262 sulle rispettive piazzole (footprint). Fissare gli angoli prima di rifluire i contatti.

3. Connessione dell'Antenna e Test RF

Saldare il connettore SMA. Attenzione: Non accendere mai l'unità senza aver prima connesso un'antenna idonea o un carico fittizio da 50 Ohm, al fine di evitare la rottura immediata dello stadio finale di potenza.
