Ecosystem Aegis-Beacon v5.4

~$23-28 BOM 410–525 MHz 65 h BEACON · 44 h SEARCH 4 Modes

A low-cost emergency radio-location system based on LoRa, designed for mountain rescue, land operations, and critical civilian scenarios. The beacon generates CW pulses and long-range digital messages to support radio direction finding when cellular infrastructure is unavailable.

[ SCOPE ]

Alpine and Backcountry Rescue

Enables missing persons to transmit a stable Morse trace (CW 600 Hz) that can be located by SAR teams with PMR446 receivers, AM scanners, or SDRs. Antenna: 17.3 cm quarter-wave at 433 MHz.

[ TECHNOLOGY ]

FSK / CW Keying (SX1262)

Continuous 0.6 kbps FSK carrier with CW keying through transmitDirect(), indistinguishable from OOK during reception. TX −9…+22 dBm via RadioLib (up to +30 dBm with the onboard E22 PA).

[ INDEPENDENCE ]

Zero Infrastructure

No dependency on GSM, Wi-Fi, or commercial satellites. Direct peer-to-peer communication at 410–525 MHz. CONFIG mode is used only for setup (WiFi AP 192.168.4.1).

RF Unit Hardware Architecture

The radio core couples the dual-core ESP32 microcontroller with the Semtech SX1262 long-range transceiver. This combination provides precise carrier generation and low power consumption during deep sleep.

[ RF Amplifier Stage ]

The Ebyte E22-400M30S is based on SX1262. It integrates a power amplifier (PA) and a low-noise receive amplifier (LNA) to extend the link budget beyond 15 km in clear line of sight.

[ Power System ]

Integrated TP4056 Li-ion charging circuit with voltage monitoring through a resistor divider connected to the ESP32 ADC pin for discharge telemetry.

Physical Characteristics

Antenna Connector 50-ohm female SMA
System Clock XTAL 32 MHz (TCXO ±1 ppm)
Deep-Sleep Current ~10 µA
Enclosure Hammond 1593L (100×60×25)
BEACON Runtime ~65 h (no GPS)

Firmware Infrastructure

Written in C++ (Arduino/PlatformIO), based on RadioLib ≥ 6.x for the SX1262 front end, U8g2 ≥ 2.34 for the SSD1309 display, and TinyGPS++ ≥ 1.0.3 for NMEA coordinates. The WiFi/BT stack is disabled in BEACON/SEARCH to save ~120 mA.

Four modes (BEACON / SEARCH / CONFIG / EMERGENCY) with ~10 µA deep sleep, a 30 s hardware watchdog, IRQ-driven DIO1, and mandatory polling of SX1262 BUSY GPIO 21.

[ SOFTWARE BUILD PROCEDURE ]

Firmware Update and Flashing with PlatformIO

The Aegis-Beacon firmware is compiled to machine code and executed directly on the ESP32 chip. Follow the tool sequence to upload corrective software patches or calibrate operating frequencies.

STEP 01 // PREPARATION

Download and install Visual Studio Code with the PlatformIO IDE package. Clone the development Git repository in the local terminal. 

git clone https://github.com/Leo-Galli/Aegis-Beacon.git
STEP 02 // UART CONNECTION

Connect the beacon to the computer through a USB-TTL converter (CP2102 or FTDI). Connect RX to TX, TX to RX, and share GND. Pull GPIO0 to ground at startup to enable flash bootloader mode.

STEP 03 // BUILD AND FLASH

Open the project folder in VS Code, verify the parameters in platformio.ini, and run the combined build and hardware upload command. 

pio run --target upload
[ STRUCTURAL ASSEMBLY PROCEDURE ]

PCB Soldering and Physical Construction Manual

Assembly of the Aegis-Beacon unit requires precision and basic SMD (Surface Mount Device) soldering skills. Follow the component assembly plan carefully to avoid shorts or thermal damage to sensitive RF sections.

Bill of Materials (BOM) Specifications

  • MCU: ESP32 DevKit V1 30-pin (Espressif, ~$3)
  • RF: Ebyte E22-400M30S (SX1262, +30 dBm PA, ~$5.50)
  • Display: SSD1309 2.42" OLED 128×64 (SW SPI, ~$3.50)
  • GPS (opt): NEO-6M UART2 9600 baud (~$4.50)
  • Audio: DAC1 GPIO25 → 100Ω → 10µF → jack 3.5mm
  • Power: TP4056 USB-C + 18650 Li-ion (~$0.50+1.50)
  • TCXO: onboard 32 MHz ±1 ppm via E22
  • Estimated total BOM: ~$23-28 USD

Step-by-Step Operating Guide

1. Passive Component Soldering

Solder the 0805 or 0603 SMD resistors and capacitors first, preferably using high-conductivity solder paste and a hot-air station.

2. Allineamento dei Moduli Integrati

Position the ESP32 and SX1262 chip accurately on their respective footprints. Tack the corners before reflowing the contacts.

3. Connessione dell'Antenna e Test RF

Solder the SMA connector. Warning: never power the unit without first connecting a suitable antenna or 50-ohm dummy load, otherwise the power amplifier stage may fail immediately.
