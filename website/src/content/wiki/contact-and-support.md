# Contact and Support

Getting help is a skill, and the wiki is written to make it fast. This page is the help path, in order.

## The help ladder

| Step | Where | When |
| --- | --- | --- |
| 1 | This wiki's [Troubleshooting](troubleshooting) | Always first: the answer is usually here |
| 2 | The [FAQ](faq) | For the common questions |
| 3 | The issue tracker | When the wiki did not answer (see [Reporting Issues](reporting-issues)) |
| 4 | A [field report](community-resources) | When you found something new |

## What makes help fast

| Include | Why |
| --- | --- |
| Firmware version | Behavior differs between versions |
| Board and modules | Wiring advice depends on the hardware |
| The serial log | The firmware's own diagnosis (see [Serial Monitor Guide](serial-monitor-guide)) |
| What you already tried | No one repeats your work |

## What makes help slow

- "It doesn't work" with no version, log or scenario
- A screenshot of a screen with no context
- Asking before reading the [Troubleshooting](troubleshooting) page

## The guarantee

The maintainers read every report, but the wiki is the shared memory: the answer you got today becomes the page someone reads tomorrow. The [Contributing](contributing) page explains how.
