# Field Signals Cheat Sheet

The signals card: everything you might send or receive in the field, one page. The full treatments are linked under each section.

## Whistle (see [Whistle Signals](whistle-signals))

| Signal | Meaning |
| --- | --- |
| Six blasts, pause, repeat | Distress |
| Three blasts | Reply: we hear you |
| One long blast | Attention |

## Mirror (see [Mirror Signaling](mirror-signaling))

| Flash | Meaning |
| --- | --- |
| Slow rhythmic flashes | Attract attention |
| SOS rhythm (3-3-3) | Distress |
| Steady at the aircraft | Confirm position |

## Ground signals (see [Ground to Air Signals](ground-to-air-signals))

| Symbol | Meaning |
| --- | --- |
| V | Need assistance |
| X | Need medical assistance |
| Arrow | Proceeding this way |
| Y / N | Yes / No |

## Radio (see [Mayday vs Pan Pan](mayday-vs-panpan))

| Prefix | Meaning |
| --- | --- |
| MAYDAY x3 | Immediate danger |
| PAN PAN x3 | Urgent, not immediate |

## The beacon itself

SOS + identity + coordinates, repeating on schedule: the automatic layer under all the manual signals (see [Emergency Cheat Sheet](emergency-cheat-sheet)).
