# Pre-Trip Checklist

## Overview

A beacon is only useful if it is charged, configured for the right region, and verified to transmit before you need it. This checklist takes five minutes at home and none in the field.

## The Checklist

| # | Check | Pass criteria |
|---|-------|---------------|
| 1 | Battery | >= 80% on the OLED, no low-battery blink |
| 2 | Frequency plan | Matches the region (see Frequency Compatibility) |
| 3 | Payload | Name and GPS enabled if you want them transmitted |
| 4 | GPS | Fix acquired outdoors before you pack it |
| 5 | Test TX | One beacon cycle heard on an SDR or second radio |
| 6 | Audio | Jack produces the Morse click stream |
| 7 | Buttons | MODE toggles, SEL opens CONFIG, all feel crisp |
| 8 | Case | Sealed, antenna tight, no rattling |
| 9 | Spare cell | Charged and stored correctly (see Charging and Cell Care) |

## Field Repeat

When you reach the trailhead, do the short version:

1. Power on and confirm battery %.
2. Confirm the OLED shows the configured frequency.
3. Trigger one test cycle and listen.
4. Switch to the intended operating mode (BEACON normally).

## GPS Notes

- Acquire a fix at the car, not in the valley shadow.
- Confirm the payload contains coordinates on the OLED scroll.
- If no fix after 60 s, check the patch antenna placement.
