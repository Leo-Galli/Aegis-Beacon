# Community Resources

The project is open source, and its community lives in the usual places. This page is the map.

## The repository

The source of truth for everything: firmware, website, wiki, and issues live in the project's GitHub repository. The [GitHub Workflow Guide](github-workflow-guide) explains how to use it.

## The places to talk

| Place | For |
| --- | --- |
| GitHub issues | Bugs and feature requests (see [Reporting Issues](reporting-issues)) |
| GitHub discussions | Questions, builds, field reports |
| Pull requests | Contributions (see [Contributing](contributing)) |

## The knowledge base

This wiki is the knowledge base, and it is itself a community artifact: pages are proposed, reviewed and merged like code (see [Contributing](contributing)). The [Roadmap](roadmap) documents what the community has asked for and what is planned.

## The field report culture

The most valuable community contribution is the field report: what worked, what broke, what the [Beacon Log Template](beacon-log-template) caught. Reports like that are how the roadmap stays honest (see [Feature Requests](feature-requests)).
