# Quick Reference Sheet

The numbers every beacon user needs, on one page. Print this for the case lid or the field notebook.

## Default settings

| Setting | Default |
| --- | --- |
| Frequency | 433.920 MHz (planned channel recommended) |
| Power | Legal floor (+10 dBm) for routine use |
| Sleep interval | 10 s |
| Repeat count | 1 |
| Tone speed | 12 WPM |
| GPS | On (if fitted) |

## Button actions

| Action | Function |
| --- | --- |
| MODE | Cycle modes (BEACON -> SEARCH -> CONFIG -> ...) |
| SEL | Select / confirm |
| UP / DN | Adjust the selected value |
| MODE + SEL (5 s) | Factory reset (see [Factory Reset and Recovery](factory-reset-and-recovery)) |

## The emergency numbers

| Item | Value |
| --- | --- |
| Distress signal | SOS |
| Whistle distress | Six blasts |
| Whistle reply | Three blasts |
| PMR446 emergency channels | See [PMR446 Deep Dive](pmr446-deep-dive) |

## The field rules

1. Antenna up, clear of metal (see [Antenna Height Matters](antenna-height-matters)).
2. Scan before deploying (see [Scanning the Band](scanning-frequency-table)).
3. One test burst decoded before the trip (see [Pack Check Routine](pack-check-routine)).
4. The battery monitor warns; the [Battery Field Swap](battery-field-swap) fixes.
