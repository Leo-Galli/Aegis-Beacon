# Branding

The Aegis-Beacon brand is the visual identity of a rugged rescue instrument: dark, precise, signal-orange accents, and technical typography. This page documents the identity; the website's branding page shows it live.

## The mark

The beacon mark is a lighthouse-style beacon symbol: the signal the device exists to send. It appears in the site header, the favicon, the shared images, and the repository's banner.

## The palette

| Role | Colour |
| --- | --- |
| Surfaces | Graphite dark tones for the interface |
| Ink | Near-white text on dark surfaces |
| Accent | Signal orange: the "this matters" colour |
| Data | Terminal green and blue for radio/GPS values |

The palette is tokenized in the design system, so both themes (dark and light) share the same structure with swapped surface colours.

## The typography

| Face | Role |
| --- | --- |
| Chakra Petch | Display and headings: technical, angular |
| Manrope | Body text: readable, neutral |
| JetBrains Mono | Data, coordinates, terminal output |

All fonts are self-hosted; the site makes no external font requests.

## The voice

The brand's written voice matches the hardware: plain, precise, and calm. Copy names things by what they do ("Start the burst", not "Initiate transmission"), and the error states explain what happened and what to do (see [SEO](seo) for the copy rules).

## Where the brand lives

| Surface | Element |
| --- | --- |
| Website | Header, footer, shared cards (see [SEO](seo)) |
| Wiki | The same design system, the same voice |
| Repository | Banner, README, release assets |
