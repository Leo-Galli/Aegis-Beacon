# Roadmap

The roadmap is the honest list of what the maintainers want next, in priority order. It changes as field experience accumulates; nothing here is a promise.

## Firmware

| Idea | Status | Why |
| --- | --- | --- |
| Payload acknowledgment (two-way) | Design | Would turn the beacon into a rescue dialog |
| GPS averaging before TX | Planned | Cleaner coordinates in the payload |
| Config presets (fast switch) | Planned | Field users switching between missions |
| Better scan display | Idea | The SEARCH mode is usable but basic |

## Hardware

| Idea | Status | Why |
| --- | --- | --- |
| Smaller SMD board | Idea | The dev-board build is bulky |
| Solar input reference design | Planned | Multi-day missions (see [Solar Build](solar-build)) |
| Waterproof case as an official design | Idea | Sealing is currently a user skill |

## Documentation

| Goal | Status |
| --- | --- |
| More language versions of the wiki | Planned |
| Video build guide | Idea |
| Field handbook (printable PDF) | Planned |

## How to contribute

Every item on this list is open for contribution. The honest path: discuss it as an issue first (see [Reporting Issues](reporting-issues)), then build it on a branch (see [Contributing](contributing)). The best roadmap items come from field users who found a real gap.
