# Morse Code Learning Apps

Morse learning has good software now: spaced-repetition drills, adjustable speeds, and real signals. This page is the practical shortlist, including the beacon's own tools.

## The beacon's own tools

| Tool | What it does |
| --- | --- |
| The website [Demo](/demo) | Plays the payload as Morse at adjustable WPM |
| [Morse Decoder Tools](morse-decoder-tools) | Decodes recorded bursts |
| The beacon itself | Transmits the real signal to practice against |

Nothing beats the real device for learning the actual signal you will hear.

## The app shortlist

| Tool | Strength |
| --- | --- |
| Koch-method trainers | Start at the letters' full speed, add letters one at a time: the fastest proven method |
| Farnsworth-speed apps | Slow gaps, fast characters: the right first setting |
| Spaced-repetition flashcard apps | The letter table (see [Morse Letter Table](morse-letter-table)) as cards |
| CW decoders | Training wheels: decode alongside you, then turn them off |

## The method that works

1. Learn 2 - 3 letters per session, Koch method.
2. Listen at full character speed with long gaps (Farnsworth), never slowed-down characters.
3. Practice against the beacon's actual payload: SOS, identity, coordinates.
4. Ten minutes daily beats two hours weekly.

## The goal for beacon work

Stage 1 (see [Morse Keying Practice](morse-keying-practice)): recognize SOS instantly, copy your callsign, read a coordinate string digit by digit. Apps get you there in a few weeks of daily ten-minute sessions.
